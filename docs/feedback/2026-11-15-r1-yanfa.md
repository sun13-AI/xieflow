## 过程记录（关键坑与解法，供后续轮次复用）

1. **pnpm 11 弃用 `onlyBuiltDependencies`** → `pnpm-workspace.yaml` 用 `allowBuilds: {esbuild: true}`；且 v11 不再读 package.json 的 `pnpm` 字段
2. **根 package.json 缺 `"type": "module"`** → tsx 按 CJS 转译，e2e 顶层 await 报错；补上即解
3. **node-sqlite3-wasm 是 CJS 包** → ESM 下用默认导入解构 `const { Database } = sqlite3Wasm`
4. **PS 5.1 读无 BOM UTF-8 中文脚本会语法炸** → shot.ps1 改纯 ASCII 注释/输出
5. **Windows 125% 显示缩放让 headless CSS 断点不可靠** → 窄屏形态用 `?narrow=1` 显式钉态（与媒体查询同规则），不赌视口宽度
6. **SQLite CHECK/NOT NULL 不拦空字符串** → 服务层显式抛错（空 key/空标题两个用例）
