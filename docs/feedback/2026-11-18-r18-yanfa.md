## 六、自曝（遗留问题，不阻塞收尾）

1. **密码哈希为同步 PBKDF2（120000 次）**：单次约数十毫秒，注册/登录低并发场景可接受；高并发时应改为异步 worker/Argon2（仍守 shared 唯一入口）。
2. **登录接口支持 `ttlMs` 缩短会话**：这是为 HTTP 层真实测「过期会话 401」留的本地自测 seam，上界即默认 2h、下界 1ms；生产部署建议移除或仅管理员可用。
3. **首个注册用户自动成为 admin**：自托管首启引导，无邀请码/审批流；多租户场景需 lead 评估是否改为显式引导令牌（不属本轮任务单）。
4. **token 存 localStorage**：XSS 可读取；未用 httpOnly Cookie（后者需跨站与 CSRF 设计）。本轮为单机/自托管起步，已在认证页脚注如实标注。
5. **无登录失败次数限制 / 锁定**：M9 起步轮未做暴力破解防护；remote 公网部署前需补 rate limit。
6. **模式切换在 local 状态下匿名可用**：设计为本机自托管动作；切到 remote 后再改模式即要求管理员 token（audit 已锁 403）。若远端部署暴露该端点，建议由环境配置固定。
7. **截图 01~05/07/08 为钉态**：seed 阶段的注册→登录→guard→登出是真 HTTP，但截图本身不展示浏览器内真实 localStorage token；remote 跳登录另有非钉态 headless DOM 证据（第四节）。
8. **remote 鉴权按 `/api/` 前缀在 onRequest 钩子统一拦截**：新增业务路由自动受保护；但非 `/api/` 静态资源不走鉴权（符合预期）。
9. **无密码找回 / 邮箱验证 / 外部 IdP**：后者命中危险区，明确不做；前两者需外部服务，留后续轮。
10. **CRDT 协同编辑未做**：按路线图推迟到 M10 前，本轮只铺认证通道。
11. **三平台 CI / unix pwsh 7 分支未实跑**：shot.ps1 新增段全 ASCII、PS5.1 Parser 0 错误；本机 Windows 限制，属 lead 发版环节。
12. **`docs/plan.md` 记账未改**：路线图记账 / 版本 / tag / push / Release 属 lead 收尾职责（宪法第二、五条），本轮严格未触碰。
