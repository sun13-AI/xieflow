## 三、行为链路实证

- **纯函数**：`canStartTodo` 对 A→B→C 链，A open 时 B/C 均 false；A done 后 B true、C 仍 false；A/B done 后 C true。`detectDependencyCycle` 自环/两节点/三节点分别返回 `[a,a]` / `[a,b,a]` / `[a,b,c,a]`，DAG 返回 null。`buildDependencyGraph` 拓扑序 `[1,2,4,3]`，C 的传递阻塞链 `[1,2]`，全链完成后 blocked 清零。三组输入快照前后 `JSON.stringify` 逐字节相等（只读证据）。
- **真 HTTP**（scratch 库）：A/B/C 三探针 + B←A / C←B 链；A open 时 PATCH B/C done → 409 + `DEPENDENCY_BLOCKED` + blockers=[A]，B 仍 open（零半态）；自依赖 400 / 环 400 + cycle / 重复 409 / 越权 404 / 非法 body 400；A done → B 解锁 → B done → C done；DELETE 前置与删实体 CASCADE 均真回查归零；探针全删。
- **「用户第一次用」全链路**（headless CDP 真点，`scripts/r34-firstuse-cdp.mjs`，Edge `--headless=new`，零可见窗口）：HTTP 造 A/B/C → 设 B←A / C←B → HTTP 409 预证 → 页面显示 B「被 1 项阻塞」→ 真点 B「前置任务」面板，A 作为前置且状态徽标为「进行中」→ 真点 B「完成」得内联 409 红条且 B 仍 open → 真点 A「完成」→ B 阻塞徽标消失并显「前置已满足」→ 真点 B「完成」成功 → reload 后 B 仍 done、B←A 依赖 HTTP 回查仍在 → 三探针 DELETE 归零。**日志末行 `R34 FIRSTUSE: ALL GREEN`（17 步全绿）**。
- **既有 todo 状态机零回归**：r1 的 open→done / done→open / open→archived / archived→done 非法四态断言全绿；本轮只加 `to === "done"` 且存在未完成前置时拦截，无依赖时语义逐字不变。
