### 2.2 手算 vs 实测（独立脚本按契约公式从零实现，未 import 项目代码）
分词口径：中文逐字、英文/数字成词；`idf(t)=ln((1+N)/(1+df(t)))+1`，`N=3`（三片语料）；`tf=词频/片内 token 数`；`score=cosine(q,d)`，零交点过滤、score 降序。

- 查「苹果」：`q=[苹,果]`，`df(苹)=df(果)=2` → `idf=ln(4/3)+1=1.287682`，`qVec` 各 `0.5×1.287682=0.643841`，`‖q‖=0.910528`。
  - 科技稿：`tf(苹)=tf(果)=4/12`，其余 4 词 `df=1 → idf=1.693147`；手算 score **0.9068029489615511**，API 同值，排第 1。
  - 水果稿：`tf(苹)=1/6, tf(果)=2/6`；手算 **0.6646437508988071**，API 同值，排第 2。
  - 菜谱稿：零交点 → 手算过滤、API `count=2` 未返回（**无关文档零分过滤**成立）。
- 查「香蕉」：仅水果稿命中，手算 = API = **0.5826177734324463**。
- 查「番茄」：仅菜谱稿命中，手算 = API = **0.5**。
- 三组查询的命中顺序、条数与分数**逐位一致**，非"差不多"。

### 2.3 来源可溯源
「苹果」两条命中的 `docId=8/chunkId=8`、`docId=9/chunkId=9` 分别 `GET /api/knowledge/docs/{id}/chunks` 找到同 id、同 position=0、内容逐字相等的存储 chunk；`docTitle/sourceType` 与单篇文档读回一致。UI 侧显示「来源：… · chunk #id · 第 N 片 · 纯文本」并在 CDP 站内可点查到（见第五节）。
