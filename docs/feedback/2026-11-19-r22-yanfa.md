3. **e2e 计数两种口径**：本轮 finale 在**服务收净后**复跑，离线 1856；变异红相取证时 api 仍在线，故当时输出 1856 通过 / 1 红 = 在线总数 1857。README 统一按离线口径（与 r21 1842 同口径），两处已标清。
4. **「更多」入口的可见性 seam 是纯函数 + DOM 属性**，不是像素级断言；截图证明画面有入口，e2e 证明条件接到 `data-state="tabs-more"` / `data-more-visible`。变异证明的是 seam 断言非恒真，不等于「按钮渲染失败时截图会自动红」。
