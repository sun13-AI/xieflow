根因（实跑定位，`apps/api/src/server.ts:224-236`）：①`listSchedulesByDateRange` 只查本体 date 落窗内的行，锚日在窗外的循环日程根本不会进入展开流程；②展开循环里 `!seen.has(inst.id + inst.date.length * 0)` 等价于 `!seen.has(inst.id)`，而本体 id 在同一轮已加入 `seen`，恒为假——**实例永不入列**。e2e 的 14 条循环断言全部直接测纯函数、audit 的区间查询断言只查 none 本体，无一条经由 HTTP 端到端覆盖「实例出现在区间查询」，属断言面真实空洞（宪法第四条第 4 点同类问题）。
