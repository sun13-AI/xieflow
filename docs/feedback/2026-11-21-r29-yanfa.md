### 变异红相留痕（宪法第四条）

- **变异点**：`packages/shared/src/docHistory.ts` 的 `nextDocVersion` 唯一递增语句 `return n + 1;` → `return n; // MUTATION-PROBE r29: restore would overwrite instead of producing a new version`。语义等价「恢复覆盖历史版本」的病根。
- **改前 SHA-256**：`0782FBBCD88B4A700E819242B76C1FD8506930CC4DA2D3A7C065103DBC92645D`。
- **变异态实测**：`pnpm test` exit 1，**4 条显式红**（空历史下一版 got 0 want 1 / v1 下一版 got 1 want 2 / v3 下一版 got 3 want 4 / 字符串版本号 got 2 want 3）+ 数据层 `createDocumentVersion` 触发 `CHECK constraint failed: version > 0` 中断；`node scripts/run-ps1.js scripts/audit-http.ps1` exit 1，**11 条红**（存 v1/v2/v3 快照 400≠201、首版/二版/三版号 undefined、v1 内容逐字不等、摘要缺失、真 HTTP 三版 got 0 want 3）。
- **逐字节还原**：从 `%TEMP%\r29-docHistory-pre-mutation.ts` 拷回；改后 SHA = 改前 SHA（MATCH=True）；`MUTATION-PROBE r29` 在 `packages/` `apps/` `scripts/` **0 命中**；备份文件已删。

## 三、「用户第一次用」全链路（真 HTTP，scratch 库 0 探针起步）

scratch 库（`%TEMP%\r29-shot\scratch.db`，api 8787 隐藏窗口）+ headless 页面（`?page=docs&shot=docs-*`，`isolatedContext` 无头）：

1. **建文档**：`POST /api/documents` 得 id=1，默认首块自动在场（零块死路已闭）。
2. **存 v1**：`import.md` 写入「# r29 版本一 / first paragraph / second paragraph」→ `POST /:id/versions` 得 v1，note「变更摘要：新增 5 行 / 删除 0 行」，`GET /:id/text` 记录基线全文。
3. **改 → v2 → v3**：两次 `import.md` 改写正文并各存一版，得 v2 / v3，note 分别含增删行数；`GET /:id/versions` 回 3 版（新版在前）。
4. **恢复 v1**：`POST /:id/versions/1/restore` → 回 `restoredFrom=1`、新版本 `version=4`、`contentMarkdown` 逐字等于 v1；`GET /:id/text` 与步骤 2 基线全文**逐字相等**；再查版本列表 4 版，原 v1 快照未变。
5. **软删 → 回收站**：`DELETE /:id` → 200 且 `soft:true`；常规 `GET /:id` 404、列表排除；`GET /api/documents/trash` 可见该项且带 `deletedAt`。
6. **还原 → reload 不丢**：`POST /trash/:id/restore` → 200，再 `GET /:id` 恢复 200、四版版本历史仍在（等价于页面 reload 后数据不丢）。
7. **永久删除**：再次软删 → 缺 confirm 400；带 `confirm=PERMANENTLY_DELETE` 200 → `GET /:id` 404、回收站归零；**只删本轮探针**，仓库 `data/xieflow.db` 未写。
8. **收净**：`shot.ps1 down` 后 8787/5173/8788 listen 全 0；截图种子文档经同一永久删除路由清理，零残留。
