## 六、自曝（遗留问题，不阻塞收尾）

1. **TF-IDF 是本地词频算法，非语义向量**：中文逐字 / 英文成词、无词干化与同义词扩展；`NO_EMBEDDING` 只是接口留位，`vector` 列当前恒 NULL。真实语义检索待接 embedding provider（M6 收官 r13 或后续轮）。
2. **分块是确定性启发式**：优先断在窗口后 40% 的换行处，无换行则硬切；`chunkSize` 极小（≤overlap+1）时主动放弃重叠以保证滑窗单调推进（e2e 有单片保底断言，非丢字）。
3. **文档源入库无增量同步**：`source_type='document'` 的 chunks 是入库时点快照，源文档后续改动不会自动重索引；UI 删知识文档不影响源文档，反之删源文档会 CASCADE 删知识文档（schema 外键语义，符合任务单但需用户知晓）。
4. **知识文档只有文档级 CRUD**：无单块更新/删除端点；搜索命中的来源引用可定位到 chunk，但修改需删整篇重入库。
5. **`knowledge_docs.content` 存全文 + chunks 存分片**：有少量冗余，换取来源可审计与重算 token 的便利；大文本入库体积约为正文 2 倍，当前 20 万字上限足够。
6. **命中高亮是前端按 query token 正则切分**：不依赖服务端偏移；同音/变体词不合并高亮（与 TF-IDF 分词口径一致）。
7. **九药丸窄屏用 10px 微缩 + `overflow-x:auto` 兜底**：488px 下实测单行不折行不裁切（06 图）；更窄容器（<440px）仍可能出现的横向滚动未逐一实测。
8. **本机无 pwsh 7**：shot.ps1 新增段全 ASCII（87490 B、非 ASCII 0、PS 5.1 `ParseFile` 0 错误），unix 分支未实测（与 r5~r11 同款未验项）；三平台 CI 未实跑（属 lead 发版环节）。
9. **e2e 在线口径**：1087 为服务离线口径；api 在线时 HTTP 冒烟节 +1 = 1088，README 已括注。
10. **未做发版动作**：版本号 / tag / push / Release 资产核对属 lead 收尾（宪法第二条 + 第五条危险区），本轮严格未触碰；`docs/plan.md` 的 r12 记账与进度看板留 lead 收尾写入。
