## 六、自曝（遗留问题，不阻塞收尾）

1. **折叠状态不跨 reload**：折叠集合是前端内存 state，reload 后回到全展开（Markdown 源与树不丢）；若要持久化需加 localStorage 或后端字段，本轮任务单未要求。
2. **树→Markdown 只走编辑框**：右侧节点目前只读（折叠/展开除外），不支持拖拽节点改写 Markdown；`treeToMarkdown` 已具备装配能力且被 audit/e2e 锁定，UI 反向编辑留后续轮。
3. **代码围栏作单个 text 节点**：整段围栏（含内部 marker）作为一个节点保留 raw，不在树里展开行级结构；保证不丢内容，但树视图对代码块的层次感弱。
4. **未知语法逐字降级**：表格/加粗/HTML 等按整行 text 节点展示，不做富文本渲染；与 r9 文档块「逐字降级」口径一致。
5. **无鉴权**：单用户阶段 `mindmaps` 路由只校验 id 存在性，不做用户级权限；越权 id 以 404 表达。
6. **十药丸在 1280 窄容器可能横向滚动**：`.tabs` 强制 nowrap，窄屏由 `overflow-x:auto` 兜住；十 tab 壳基线逐张目验无折行，未做 <440px 逐档实测。
7. **本机无 pwsh 7**：shot.ps1 新增段全 ASCII（非 ASCII 字节 0、PS 5.1 `ParseFile` 0 错误），unix 分支未实测（与 r5~r13 同款未验项）；三平台 CI 未实跑（lead 发版环节）。
8. **`docs/plan.md` 记账未改**：路线图记账 / 版本 / tag / push / Release 属 lead 收尾职责（宪法第二条 + 第五条危险区），本轮严格未触碰；plan 中 r14 仍为预占行。
9. **seed id 不连续**：shot.ps1 每轮 seed 一张导图后 DELETE，`AUTOINCREMENT` 计数不回退；截图索引记录的是当轮 seed id（#1），CDP 全链路新建的是 #2，均是真数据。
