## 四、「用户第一次用」全链路（headless CDP 真点，0 数据起步）

在 scratch 库的 api（8787）+ web（5173）上，用 harness 无头浏览器 CDP 真点：
1. `?page=org` 空态 → 点「＋ 新建部门」建 **CDP集团总部**（#1）→ 再建 **CDP研发中心**（#2，父 #1）→ 再建 **CDP前端组**（#3，父 #2），三级树真实落库；
2. 点「＋ 新建人员」建 **CDP张三**（邮箱 `CDP.Zhang@Example.COM`，部门 #3，职位 `Frontend Engineer`）→ 卡片出现；
3. 搜索框输入 `ENGINEER` → 命中该人员（大小写不敏感）；
4. 展开研发中心 → 选中前端组 → 移动面板选「CDP集团总部」→ 提示「部门已移动」，树层级即时变为 #1 直挂 #2/#3；
5. **reload** → DOM 回读三部门 + 一人员仍在；`GET /api/org/tree` 回读 `#3.parentId=1`、人员 `departmentId=3`、邮箱原大小写保留；
6. DELETE 探针人员 #1 与部门 #3/#2/#1（4×200）→ 复回查 `departments=[] / members=[] / tree=[]`，端口收净，scratch 库已删。
   全流程零可见窗口；真点击与 DOM 量测由 CDP 完成，持久化证据由 HTTP 回查完成。
