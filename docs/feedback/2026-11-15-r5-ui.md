## 七 · 专项裁决：「r4 目录看板图仍是 r5 前形态」是否构成 U1？

**判定：不构成 U1。** 四条依据：

1. **宪法第一条的对象是「当轮受影响页面 × 交互状态」的证据，且载体是当轮目录。** r5 的渲染层受影响面只有看板页（新增统计卡 + 导出按钮），r5 目录已交付看板页新形态 8 张（任务单 5 态 + 弹窗 + 加载 + 错误），其中 01/02/03 走真实链路。**当轮证据位无空缺。**
2. **r4 目录是 r4 轮的历史证据，保留历史形态恰恰是它的正确职责。** 改写 r4 目录反而会篡改历史事实（r4 复审对 04/05 移动证据链、13/05 同态的裁决都依赖那批图的原始状态），并造成同一目录混批。
3. **不存在「旧图冒名新形态」的造假**——这正是 r3 U1-1（06/10 字节级相同却标不同状态）的反面。研发主动披露（r5 README 注记 4 + 根 README r4 小节指针），读者不会被误导；实测 r5 的 8 张与 r4 的 12 张看板图两两互异，壳基线 5 张也为本轮重拍（mtime 同批、画面新壳）。
4. **唯一残留是索引陈述失效**（r5 README 同态分组少列了 shell 图的归属变化、r4 README 同态披露节已被重拍打破；board-tab-active 差异原因写错）——属文档准确性，**记 U3-4，不阻断**。

**反向检验（若成立则是 U1）：** 若 r4 目录的旧看板图被拿去做 r5 的证据位（拿旧图充新形态），则构成 U1。实测无此情形。**故：不予打回，仅要求下轮把两处同态披露节的失效标注修正。**
