## 六、自曝（遗留问题，不阻塞收尾）

1. **画布视口不跨 reload**：平移/缩放 state（pan/scale）为前端内存态，reload 回初始 (40,40,100%)；便签坐标与内容不丢。任务单未要求持久化，若要保留需加 localStorage 或后端字段。
2. **AI 建板是追加而非替换**：`POST /:id/ai-create` 在既有条目之上追加 7 张；若板上已有便签与之重叠，避让会把部分草稿推到更下方（CDP 中 #36 落到 y=408），仍在画布内但可能需平移才能看到。符合「不删用户数据」纪律。

4. **便签拖拽只测鼠标指针**：CDP `drag` 走真实 pointer 事件；触屏多指/惯性滚动未实测，`touch-action:none` 已设但无真机验证。
5. **无鉴权**：单用户阶段 whiteboards 路由只校验 id 存在性，越权 id 以 404 表达（与其它轮同口径）。
6. **导出文件名**：ASCII 回落名 `xieflow-whiteboard-<id>.md`，中文标题走 RFC 5987 `filename*=UTF-8''`；未在 Excel/Word 真开验证（导出内容是 Markdown 文本）。
