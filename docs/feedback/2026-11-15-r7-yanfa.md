## 五、自曝（遗留问题，不阻塞收尾）

1. **视图筛选仍是「等值 / 包含」语义**：多条件之间是 AND，但没有区间（`金额 > 1000`）、OR、模糊匹配；任务单只要求「多字段 AND」，区间留后续轮次。
2. **CSV 导入无交互式列映射面板**：表头必须精确等于字段名或字段 id 字符串；未知列直接 400（整表级错误，非行级）。对「从别处导出、列名不一致」的 CSV 用户不够友好。
3. **`visible_fields` 空数组 = 全部可见**：视图初次创建若用户不改勾选，落库为空数组；语义已在 README / 索引 / UI 文案写明，但与「显式列出可见列」的直觉略有落差。
4. **视图 position 不强制唯一**：只影响列表排序（同 position 按 id 兜底），与 r6 字段 / 看板列的「位置唯一」口径不一致；本轮未做重排 UI，故未收紧。
