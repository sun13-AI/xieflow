## 四、过程记录与坑（供后续轮次复用）

1. **锚日 vs 游标**（本轮最大语义坑）：循环实例化若按「当前游标」递推，monthly 会丢锚日（1-31 → 2-28 → 3-28）。实现改为**始终以原始锚日 + 月偏移**推算（`addMonths(anchor, k)`），月末收敛但不跳月；e2e 用「1-31→2-28→3-31→4-30」序列锁死该语义。
2. **TDD 断言自身也会写错**：本轮有 3 条断言因造数/语义理解偏差写错（把日程 id 当待办 id 传 FK、以为「无截止日待办也会自动生成日程」、以为 daily 在未来任意窗口都可能为空），均在红→绿循环中被抓到并**改成正确口径**（不是删断言、不是放宽断言）。红→绿本身就是抓错工具。
3. **api 停机/旧进程陷阱（新增）**：接手时 8787 上跑着**旧代码 api**（schemaVersion=2），若直接拍 r3 截图会得到「页面无日程路由」的假象。判定法：拍前先 `GET /api/health` 看 `schemaVersion=3`，否则 `shot.ps1 down` + `up` 重启。本轮已按此流程拍图。
4. **PS 5.1 ANSI 编码坑（r2 继承）**：seed 一律用纯 ASCII 标题 + 显式 UTF-8 字节数组，避免库里出现 `???????`。
5. **audit 端口残留**：`audit-http.ps1` 跑完后若残留 api 进程占着 `scripts/.tmp-audit/api.log`，下一轮 `Remove-Item -Recurse -Force` 会抛「文件被占用」。处置：按 8788 监听 PID `taskkill /T /F` 后重跑（脚本 finally 已杀，偶发孤儿）。
6. **跨平台 ps1 纪律保持**：本轮 shot.ps1 新增段全部 ASCII（含注释），未使用 `$isWindows`（pwsh 7 只读自动变量，v0.0.3 CI 教训），未使用 `-WindowStyle` 之外的 Windows 专属参数；unix 分支沿用既有实现，本机无 pwsh 7 仍未实测（见遗留）。
