## 二、字段类型引擎真实链路（本轮灵魂）——手算对表

7 种类型各建一张表（各自 8 默认字段 + 1 个该类型自定义字段），每条都走 **建表(201) → 加字段(201，type/options 读回) → 加 4~5 条记录(201，归一值读回) → 按该字段筛选(200，命中数) → 按该字段排序 asc/desc(200，序列+空值恒末) → `GET /api/records/:id` 读回**。全部 187 条断言绿，逐条 REQ/RES 见 `probe-log.txt`。关键手算对表：

- **数字**：写入 `"2"`,`10`,`"100"`,`9`,空 → 升序期望 `[2,9,10,100,null]`，实测 `[2,9,10,100,null]`（数值比较，非 `"10"<"2"` 的字典序）；降序 `[100,10,9,2,null]` 且 null 仍在最后。
- **日期**：`"2026-12-31"`,`"2025-06-15"`,`"2027-03-01"`,`"2026-1-5"`,空 → 归一后升序 `[2025-06-15, 2026-01-05, 2026-12-31, 2027-03-01, null]`，按时间轴正确。
- **单选**：候选项故意设成 `["高","低","中"]`（与 Unicode 序不同），写入 高,中,低,高,空 → 升序 `[高,高,低,中,null]` 严格按 options 下标，非拼音/Unicode 序。
- **空值**：7 类型 × 2 方向，`filled` 排序后 `empty` 恒追加在末尾（降序也是），checkbox 的 `false` 作为有效值参与 false<true 排序而非被当空。
- **多选**：子集校验 400；逗号串归一+去重；「包含」筛选 `重要`→2 命中、`紧急`→2 命中；按首个候选项下标排序。
- **复选框**：`"true"/"1"`→true、`"0"`→false；false<true；非识别串 400。
- **链接**：裸域名补 `https://`；`ftp://`、裸文本 400；字符串序。

**api 层零类型分支**：`apps/api/src/server.ts` 全文 grep `'text'|'number'|'select'|'multi-select'|'checkbox'|'url'|'date'|switch|.type ===|case "` **零命中**；5 个引擎函数 `validateFieldValue`(L817)/`coerceFieldValue`(L946)/`compareValues`(L992)/`normalizeRecordData`(L1093)/`queryRecords`(L1162) 全在 `packages/shared/src/index.ts`，e2e 有 86 条字段引擎断言 + 25 条记录装配断言锁定。

## 五、挑刺 / 边界（复验另一半职责，均记账不阻塞）

边界探针 `edge.mjs` **15/15 绿**：超长表名(201字)→400、恰好 200 字→201；超长字段名(101字)→400、恰好 100 字→201；重复删表→404、删表后字段列表→404；不存在的表/字段/记录 id→404；date/url/checkbox/multi-select 四类筛选值非法各→400。

问题分级（全部 P5「记账」，不构成打回）：

- **P5-1（别扭但没坏）**：`coerceMultiSelect` 对「既非数组也非字符串」的标量（如数字 `12345`）会静默归一成空数组 `[]` 并以 201 接受，而非按「非数组非法」拒绝。验收项⑤「multi-select 子集校验」本身正确（数组含非候选项→400），此仅 raw API 边界；UI 单元格编辑器只送字符串/数组，真实用户路径到不了。建议 r7 视图轮顺手收紧（可加断言）。
- **P5-2（体验）**：checkbox 字段按 `false` 筛选时，`null`/空单元格也命中（`matchesFieldValue` 比较的是 `value===true` 与 `filter===true`，两者皆 false 即相等）——「筛选 完成=否」会把空行也算进来。语义上「空=未勾选」可自洽，但第一次用可能意外，建议 r7 明确口径。
- **P5-3（口径澄清，非缺陷）**：「越界分页」有两种所指——**非法分页参数**（`page=0/-1/abc`、`pageSize=0`）实测全部 **400**（`parseOptionalQueryId` 拒非正整数），符合任务单 4xx 要求；而**合法但超过总页数的页码**（如 `page=999`）按 README L204「越界页返回空列表但 total 不变」的既定设计返回 **200 空列表**（e2e「分页：越界页返回空列表/ total 不变」两条断言锁定），实测 `records=0, total=1`。二者均已亲自实跑记录，非遗漏非回归。
