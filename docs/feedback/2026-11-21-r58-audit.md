### 不可达元素清单（全部 42 个，同一根因）

`apps/web/src/SchedulesPage.tsx:574-580`：

```tsx
<div
  className={`cal-cell ${c.inMonth ? "" : "cal-outside"} ${c.date === today ? "cal-today" : ""}`}
  data-date={c.date}
  onClick={() => openCreateOn(c.date)}

```

- 42 个日历格（含 `cal-outside` 补天格）带 `role="button"` 与 `onClick`，但**没有 `tabindex="0"`、没有 `onKeyDown` / Enter / Space 处理**。

- 修法建议（交 yanfa）：给每个 cell 加 `tabIndex={isPinned ? -1 : 0}` + `onKeyDown={(e) => { if (e.key === "Enter" || e.key === " ") { e.preventDefault(); openCreateOn(c.date); } }}`；或改成真正的 `<button type="button" className="cal-cell">` 并保留现有 CSS；加断言「日程页 Tab 序列覆盖 `.cal-cell[role=button]` 全部 42 个 + Enter 能开 modal」。

## 三、对比度（CDP `getComputedStyle` 实取 + WCAG 计算）

### 实测方法

CDP 在 4 个钉态页（`?page=todos&shot=ready`、`?page=todos&shot=error`、`?page=meetings&shot=meetings-conflict`、`?page=chat`）对目标选择器读 `color` / 实际生效 `background-color`（向上找首个非透明背景）/ `font-size` / `font-weight` / `opacity`，再用 WCAG 2.x 相对亮度公式在 Node 侧算比值：
`L = 0.2126 R + 0.7152 G + 0.0722 B`（各通道先 `c/255`，`c≤0.03928 ? c/12.92 : ((c+0.055)/1.055)^2.4`），`ratio = (Lmax+0.05)/(Lmin+0.05)`；正文阈值 4.5:1，大字（≥18px 或 ≥14px 且 700+）3:1。

`:root` 变量实测值：`--bg #f5f6f8` · `--card #ffffff` · `--ink #1f2329` · `--ink-2 #646a73` · `--accent #3370ff` · `--danger #d83931` · `--success #2ea121` · `--warning #ff8800` · `--border #e2e4e9`。

### 实测数据表（11 组）

| 类别 | 前景 | 背景 | 字号/字重 | 比值 | AA | 状态 |
|---|---|---|---|---:|---|---|
| 正文 `body` | `#1f2329` | `#f5f6f8` | 16px/400 | **14.59:1** | ≥4.5 | 达标 |
| 次要 `.hint` | `#646a73` | `#f5f6f8` | 13px/400 | **5.04:1** | ≥4.5 | 达标 |

### 逐条判定

1. **P1：激活 tab 白字/蓝底 4.28:1**。计算过程：`#3370ff` → R=51/255=0.2→0.0331、G=112/255=0.4392→0.1621、B=1→1；`L=0.2126×0.0331+0.7152×0.1621+0.0722×1=0.1952`；`ratio=(1+0.05)/(0.1952+0.05)=4.28`。13px/600 不满足「大字」定义（需 ≥14px 且 700+），故阈值 4.5:1 —— 差 0.22 未过。该 `.tab-active` 定义于 `styles.css:139-144`，20 个 tab 任一激活时都命中，属全局性 WCAG 1.4.3 失败。
   - 修法建议：新增 `--accent-strong: #2f68e5`（对白字实测约 **4.66:1**），仅用于 `.tab-active` 的 `background`/`border-color`；保留 `--accent` 给边框/图标，避免连带改其它组件；加断言「`.tab-active` 白字对比度 ≥4.5」。
2. 正文/次要/徽标/非激活 tab/错误红条/主按钮全部达标，零问题证明成立。
3. 禁用态混合后虽 <4.5，但 WCAG 1.4.3 明确豁免 inactive UI components；记录为已知豁免，不记问题。
