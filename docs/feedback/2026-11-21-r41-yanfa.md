## 三 · 「用户第一次用」全链路证据（headless CDP 真点）

`scripts/r41-firstuse-cdp.mjs`（一次性 Edge `--headless=new` + 临时 profile，进程退出即杀，零可见窗口）：

1. `?page=forms` 打开表单 tab → 点「＋ 新建表单」→ 真填标题 / 说明 → 首题设为文本「姓名」→ 点「＋ 添加问题」→ 第二题切数字「评分」（CDP 真 `change` 事件）→ 点「创建表单」。
2. 列表出现该表单且显示「2 道题」；点「填写」→ 填 甲/10、乙/20、丙/30 三份答卷 → 每次点「提交答卷」见绿色成功条 → 返回列表。

4. `Page.reload` → 汇总页仍在且仍为 3 份答卷（深链不丢）。
5. 独立 HTTP 回查：`GET /api/forms` 找到该表单、`GET /api/forms/:id/summary` total=3 / sum=60 / avg=20。
6. `finally` 中 `DELETE /api/forms/:id` 清探针；输出 `R41 FIRSTUSE: ALL GREEN`。
