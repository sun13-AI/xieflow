### 实测方法（与 r58 逐字同口径）

## 二、P1-2 对比度（r58 原方法：getComputedStyle + WCAG 实算）

### 实测方法（与 r58 同口径）

在钉态页用 CDP 读 `getComputedStyle` 的 `color` / 生效 `background-color`（向上找首个非透明背景）/ `font-size` / `font-weight` / `opacity`，Node 侧按 WCAG 2.x 相对亮度公式计算：`L=0.2126R+0.7152G+0.0722B`（通道 `c≤0.03928?c/12.92:((c+0.055)/1.055)^2.4`），`ratio=(Lmax+0.05)/(Lmin+0.05)`；正文阈值 4.5:1，大字（≥18px 或 ≥14px 且 700+）3:1。

### 数据对照

| 类别 | r58 前景/背景/比值 | r59 实测前景/背景/比值 | 阈值 | 判定 |
|---|---|---|---:|---|
| **激活 tab `.tab-active`** | `#ffffff` / `rgb(51,112,255)` / **4.28:1** | `#ffffff` / **`rgb(47,104,229)`** / **4.96:1**（13px/600） | 4.5 | **达标** |
| 主按钮 `.btn-primary` | `#ffffff` / `rgb(79,70,229)` / 6.29 | 同值 / **6.29:1** | 4.5 | 无回退 |
| 徽标 `.badge` | `#646a73` / `rgb(245,246,248)` / 5.04 | 同值 / **5.04:1** | 4.5 | 无回退 |

`--accent-strong:#2f68e5` 仅用于 `.tab-active`，`--accent` / `.btn-primary` 原样；实测主按钮与徽标未连带回退，研发声明的 4.96 与本轮独立复算一致（r58 建议中的 4.66 是估算，以实测为准）。
