## 五、过程记录（关键坑，供后续轮次复用）

1. **分离进程组的 api 进程会静默死亡**（r1 P1 的加重变体）：`tsx watch` 与非 watch `tsx src/server.ts` 都在「父一次性会话结束」后陆续退出（listening 后 exit 1 无堆栈）。解法：**常驻后台 job 当父进程**托管 `Start-Process`（监督循环保活），或前台 job 直连跑 api。截图窗口期结束后统一收杀。
2. **PS 5.1 `Invoke-RestMethod` 发中文 JSON body 按 ANSI 编码**：库里出现 `???????`。解法：显式传 UTF-8 字节数组 + `charset=utf-8`。node 侧（audit-http/e2e）无此问题——**乱码在测试驱动侧，不在产品链路**。
3. **`pwsh` 不在本机 PATH**（只有 Windows PowerShell 5.1）：前任 test:all 的 `pwsh scripts/audit-http.ps1` 写法在本机必炸。解法：`scripts/run-ps1.js` 包装器（node 跨平台分发 powershell.exe/pwsh），不新增依赖。
4. **headless Edge 连拍偶发一次零产出**（exit 0 但无 png）：脚本已有文件存在性守卫，重跑即过。
5. **子代理无法开常驻终端**（DSH 限制）：改用后台 job + 监督循环替代。
