## 断言对照与口径

- **统计口径（唯一入口 = shared `computeBoardStats` 纯函数）**：一张卡片算「已完成」当且仅当它关联的待办状态为 `done`；
  列完成率 = 该列已完成卡片数 ÷ 该列卡片总数；项目完成率 = 项目内已完成卡片数 ÷ 项目内卡片总数；
  **分母为 0 时完成率记 0（不除零、不出 NaN）**；结果为整数百分比（1/3 → 33%）。
- **CSV 口径**：UTF-8 BOM（字节 `EF BB BF`，Excel 双击直开）+ CRLF 记录分隔 + RFC4180 转义
  （含逗号/引号/换行的字段整体加引号、内部引号写两个）+ 中文表头 9 列；
  **每列至少一行**（空列出一行占位，卡片字段留空）。
