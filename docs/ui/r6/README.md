## 断言对照与口径

- **字段类型引擎（唯一入口 = shared）**：`validateFieldValue`（类型校验）· `coerceFieldValue`（写入前归一）·
  `compareValues`（排序比较器）三条规则全在 `packages/shared`，api / 服务层 / 界面同源，**api 层无字段类型分支**。
- **7 种字段类型**：text 文本 · number 数字 · date 日期 · select 单选 · multi-select 多选 · checkbox 复选框 · url 链接。
- **排序口径**：数值按值比 · 日期按时间比 · 单选按候选项顺序比 · **空值恒排最后（升序降序都最后）**。
- **筛选口径**：文本 / 数字 / 日期 / 单选按等值，多选按「包含」，复选框按布尔等值；筛选值类型不符 → 400。

## 已知注记（诚实披露）

1. **01/02/04/05 走真实数据路径**（seed 两张表 + `?tableId=` 深链），**03/06/07/08 是钉态**
   （`?shot=bases-fields|bases-error|bases-loading|bases-edit`）：钉态数据自洽优先，与 r2/r3/r4/r5 同款口径。
2. **筛选/排序控件的提交时机**：筛选值在**失焦或回车**时提交（真实用户操作），因此 04 用 URL 深链
   （`filterFieldId` + `filterValue` + `sortFieldId` + `sortDirection`）保证画面确定性——深链参数与界面控件同源。
3. **r5 目录的看板图仍是改名前的形态**（「完成率」而非「待办完成率」、导出文件名未含项目名）：
   本轮未重拍 r5 目录（避免破坏 r5 的「导出真值对真图」证据链），看板页当前形态以 r5 目录为准、
   文案与文件名口径以本轮代码与断言为准（U2-1/U2-2 的断言在 e2e 与 audit 中已锁）。
4. 窄屏 05 的网格**横向滚动**（网格视图在窄屏的常规做法）：首屏可见前 6 列，其余列横向滚动查看。
