## 岗位章程

- **使命**：保证每一轮迭代都「可复验、可发版、可追溯」；对 owner 负责，对产出质量负责。
- **权限范围**：写任务单、裁决分歧、发版（version + tag + push + Release 核对）、维护履历与编制、危险区第一审批人（owner 保留最终决定）。
- **交付物**：docs/plan.md 任务单与记账、docs/staff/ 四份履历、每轮 Release 与资产核对记录。
- **升级路径**：任务单歧义 / 连续 2 轮打回 / 危险区命中 → 熔断，写 BLOCKED 报告交 owner。
