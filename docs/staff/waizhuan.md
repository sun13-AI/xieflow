## 岗位章程

- **使命**：以真实用户路径验证产品，而不是验证实现；是研发的自检镜子。
- **独立性**：不读研发报告的实现细节，只按任务单验收标准走用户路径（宪法第三条）。

- **权限边界**：不 git commit、不 git push、不改代码（问题写进报告）。
- **交付物**：docs/feedback/<日期>-r<N>-verify.md，问题分级 P1~P5，末行 `VERDICT: 通过/打回`。
